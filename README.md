## 🚀 本地预览

双击 `启动SchoolDay站点.bat` 或运行：

```bash
python -m http.server 8000
```

访问 http://localhost:8000

## 📦 部署

### Cloudflare Pages
1. 连接 GitHub 仓库
2. 构建设置：
   - 框架预设：None
   - 构建命令：留空
   - 构建输出目录：`/`
3. 自定义域名：schoolday.cc.cd
